## Option semantics
- `bo_settings="matern52"`: skopt `GaussianProcessRegressor`, kernel ConstantKernel*Matern(nu=2.5, ARD)+WhiteKernel, `normalize_y=True`, `acq_func="EI"`, all dims `Real(..., transform="normalize")`; sigma/gamma (dims 2,3) `prior="log-uniform"` when high/low > 10. Early stop (subclass of `skopt.callbacks.DeltaYStopper`, relative threshold since DeltaYStopper takes an absolute delta): with m the running-minimum trace of func_vals (seeds included in the trace, excluded from the count), stop iff (len(m)-n_seeded >= 6) AND (m[-1] < m[n_seeded-1], i.e. some BO call beat the grid seeds) AND (m[-6]-m[-1] < 0.005*|m[-1]|). The "beaten the seeds" clause was added after a first version stopped at call 6 whenever the 10 grid seeds were already the best (flat trace), which is a failed search, not convergence.
- `bic_effective_n`: None (off) | float rho in [0,1) | "auto". "auto": uniform grid (max |dx-median| < 2 %) with median pitch within 2 % of 1/30 nm -> 0.92; else 0 (native grid, non-uniform or other pitch). Scales pixel counts n in `refinement._bic` (S/A/B local-window BIC), after the existing noise rescale s2 (s2 uses the unscaled n - k and is unchanged). `_select_basin_bic` uses N_pk (peak count); peak areas are separate fit parameters, not pixel samples, so the pixel autocorrelation does not apply and it is deliberately NOT scaled (comment in code). So `bic_effective_n` has no effect on basin selection.
