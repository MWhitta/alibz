## Update 2026-09-22 (coordinator defect: backlog never drains)

Original `--limit` bounded both the SELECT and the archive count, so after the
newest n were archived every later pass re-listed the same n already-archived
rows and the historical backlog was unreachable. Fixed by splitting listing
from attempts and adding a persisted backfill cursor:

- `--list-limit` (default 200, max 1000) bounds each metadata listing;
  `--limit` (default 20) bounds archive attempts per pass.
- Each pass runs two listings: `enumeration_query(list_limit)` (fresh, newest)
  and `enumeration_query(list_limit, before=backfill_cursor)` (`AND r.sequence
  < N`). `backfill_cursor`/`backfill_complete` persist in
  `<state>/cursor.json`; cursor initialises to the fresh window's min sequence.
- `_process_window` (scripts/z300_sync_tests.py:271) spends a shared attempt
  budget fresh-first; `execute_pass` (:328) advances the cursor to a backfill
  window's min **only when every row is resolved** (archived/skipped) — a
  still-pending/deferred/errored row holds it, so it is never skipped. Empty
  backfill → `backfill_complete`; `--rescan` (main :391 `_cursor_state`) resets.
- Summary gained `backfill_cursor`, `backfill_complete`, `listed_fresh`,
  `listed_backfill`.
- New tests: backlog of 5 with list-limit/limit 2 archives 2,2,1 then reports
  `backfill_complete`; a new test appearing mid-drain is archived before older
  backlog; a young no-bundle backfill test keeps the cursor at 4 across passes;
  `--rescan` re-issues the backfill query after completion. Counts below.

## What was built

`scripts/z300_sync_tests.py` (new, 369 lines): a bounded, read-only pass that
enumerates the instrument's current, non-deleted `type:"test"` documents and
archives each not-yet-archived one through `z300_opal_ingest.ingest()`.

Key functions (file:line):
- `enumeration_query` — scripts/z300_sync_tests.py:73. One transactional
  `sqlite3 -batch -noheader` SELECT in the exact style of the producer's
  `revision_query` (`test -f DB && sqlite3 ... "BEGIN; SELECT ...; COMMIT;"`);
  returns `hex(docid)|sequence|hex(json)`, `WHERE r.current=1 AND r.deleted=0
  AND replace(r.json,' ','') LIKE '%"type":"test"%'`, `ORDER BY r.sequence DESC
  LIMIT <n>`. Never by name/latest; never writes. Guarded by `test -f` so a
  missing/unreachable mount fails rather than listing empty.
- `parse_enumeration` — :101. Defensive per-row parse like `parse_revision`
  (hex decode, size cap `MAX_DOCUMENT_BYTES`, `json.loads`, re-check
  `type=="test"`, `sequence>=1`); malformed rows skipped, not fatal.
- `run_id_for` — :130. `run_id = "z300-"+test_id`, archived only when the id
  satisfies BOTH the producer rule `[A-Za-z0-9][A-Za-z0-9_-]{0,127}` and
  pantheum's `^[a-z0-9][a-z0-9-]{7,47}$`; else `(None, reason)`.
- `expected_shots_from_doc` — :152. `numShotsPerLocation*rasterNumLocations`
  from the stored config; `None` (→ skip "no stored configuration") when absent.
- `archived_test_ids` — :171. Reads `<dir>/*/manifest.json` `test_id` across
  `--archive-root` and each `--also-archived` dir. (Optional mtime cache not
  implemented; brief marks it optional.)
- `execute_pass` — :226. PendingData→`pending.json` if `unixTime` within
  `--retry-window-hours` else moved to `skipped.json`; IngestError→`skipped.json`
  with reason; unexpected → `errors` counter, pass continues. Holds
  `producer.run_lock(state_root, "z300-sync-tests")` (pass lock) plus the
  producer's per-run lock inside `ingest`. Atomic `write_json` (:206).
- `main` — :331. `--archive-root/--also-archived/--state-root/--limit
  (20)/--retry-window-hours (24)/--min-shots/--adb/--serial/--adb-port/--timeout/
  --dry-run`; summary `{listed,new,archived,pending,skipped,errors,archive_root}`
  on stdout; exit 0 ran, 2 usage, 3 unreachable (nothing listed); `--dry-run`
  prints plan JSON to stderr and touches nothing.

`tests/test_z300_sync_tests.py` (new, 15 tests). A `SyncMockAdb` executes the
producer/enumerator's real SQL against a synthetic CBL1 schema (compact JSON as
CBL stores it) and routes per-test blob `cat` reads; reuses `bundle`/
`legacy_bundle` from `tests/test_z300_opal_ingest.py`. Covers: enumeration
filters deleted/obsolete/non-test and orders newest-first; archives two new +
skips one under `--also-archived`; second pass is a no-op with byte-identical
archives and no re-reads; pending young retried next pass while old moves to
skipped (and the skipped one is not re-read); averaged-only skipped with reason
and no blob read; no-config skipped; ids failing pantheum's rule skipped;
`--limit` respected newest-first; `--dry-run` issues only the listing read and
writes nothing; unreachable → exit 3; usage → exit 2; a legacy-bundle test.
