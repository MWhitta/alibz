**Method/claim.** Reference values for NIST SRM 610-617 glasses with ISO uncertainties at 95% CL (bulk and micro-analytical), Horwitz-function quality check.

**Adoptable specifics.** Truth values and uncertainties for SRM 610-617 (trace elements doped ~450 ppm in 610).

**Where it would enter alibz.** Truth table if NIST glasses are added to the validation corpus (and for OPC reference).

**Fit-quality test.** Relative error vs reference, taking the 95% CL as the floor.

**Caveats.** Trace-element glass is a poor proxy for majors in minerals; SRM 610 majors are only ~72% SiO2 in a glass matrix.
